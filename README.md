# AB DIGITECH company site (abdigitech.net)

Static files for Neoserv web hosting (`public_html`).

## Upload

Unzip into the Neoserv hosting web root for `abdigitech.net` (usually `public_html`):

- `index.html`
- `privacy.html`
- `app-ads.txt`

No DNS changes needed — the domain already points at Neoserv hosting.

## Contents

- Homepage with company info, games, contact
- Privacy policy for AB DIGITECH apps (AdMob)
- `app-ads.txt` for Google AdMob publisher `pub-8218284322207302`
